# Number Counter 🔢

A simple, clean counter web app built with vanilla HTML, CSS, and JavaScript. Increment, decrement, and reset a number with a single click.

![CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## 🌟 Overview

This is a beginner-friendly project that demonstrates core DOM manipulation concepts in JavaScript. The app displays a number on screen and lets the user increase it, decrease it, or reset it back to zero using three buttons.

## ✨ Features

- ➕ Increment the counter by 1
- ➖ Decrement the counter by 1
- 🔄 Reset the counter to 0
- 🎨 Simple, responsive styling with hover effects on buttons

## 🛠️ Tech Stack

- **HTML5** — structure/markup
- **CSS3** — styling and hover transitions
- **JavaScript (Vanilla)** — DOM manipulation and event handling

## 📂 Project Structure

```
Number-Counter/
```

## 📖 What I Learned

Building this small project helped me practice and understand:

- **DOM Selection** — using `document.getElementById()` to grab and reference HTML elements in JavaScript.
- **Event Handling** — attaching `onclick` event handlers to buttons to trigger functions on user interaction.
- **State Management (basic)** — maintaining a simple `count` variable in JavaScript and keeping the UI in sync with it every time it changes.
- **Updating the DOM Dynamically** — using `textContent` to update what's displayed on the page without reloading it.
- **CSS Styling & Transitions** — using `hsl()` color values and `transition` for smooth hover effects on buttons.
- **Project Structure** — organizing a small front-end project cleanly into separate HTML, CSS, and JS files, and linking them together correctly.
- **Writing Documentation** — putting together a clear README so anyone (including future me) can understand and run the project quickly.
